# TableJourney Food Search for TypingMind

Search verified restaurants, cafes, markets and street food across 214 cities
from the free TableJourney API (https://tablejourney.com/api/v1). Every result
carries its source URL and last-checked date. No API key needed.

Import this plugin in TypingMind with the GitHub link to this folder.

Example prompts:

> Where can I get vegan food in Lisbon?

> Find street food in Bangkok.
